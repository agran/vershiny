# Критерии приёмки MVP

Продукт готов к публичному анонсу, когда выполнено всё ниже.

## Функциональные
- [ ] Загрузка региона Приэльбрусье одной кнопкой, объём ≤20 МБ
- [ ] Панорама 360° рендерится ≤1 с после фиксации позиции (телефон среднего класса)
- [ ] Подписи: ≥90% пиков из контрольного списка (20 вершин Приэльбрусья) показаны с верными названием/высотой/расстоянием (±5%)
- [ ] Ручная подстройка азимута свайпом; силуэт совмещается с реальным горизонтом с точностью «визуально совпал»
- [ ] Работа в авиарежиме после загрузки региона (полевой тест!)
- [ ] Фото с запечёнными подписями + координатами, шаринг через Web Share API
- [ ] Ручной выбор точки наблюдения на карте

## Нефункциональные
- [ ] iOS Safari (последние 2 версии): запрос разрешений, корректный heading
- [ ] Android Chrome: то же
- [ ] Нет сетевых запросов вне загрузки региона (проверка DevTools в офлайне)
- [ ] bundle приложения (без данных) ≤300 КБ gzip
