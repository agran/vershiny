# Экономичные DEM-тайлы для планеты (исследование)

> Итог мозгового штурма: **гибридная схема** — глобальный coarse + региональные fine,
> предрассчитанные панорамы для точек интереса.

## Бюджет

| Вариант | Размер | Охват | Вердикт |
|---|---|---|---|
| Вся планета 90 м | ~37 ГБ raw | ❌ невозможно | — |
| Гибрид (coarse + fine) | **~600 МБ** | ✅ вся планета | **рекомендуется** |
| Только патчи регионов | ~10–25 МБ | точечно | MVP |

## Архитектура (3 уровня)

```
Слой 0 (глобальный): z7 (~1.2 км), вся суша
  → горизонт «хоть какой-то» в любой точке Земли
  → ~80 МБ (квантование 4 м + дельта + gzip)

Слой 1 (региональный): z9 (~300 м), рельефная суша (размах >200 м)
  → ~250 МБ (30% суши)
  → горы, холмы, предгорья

Слой 2 (точечный): z11 (~76 м), горы (размах >800 м)
  → ~300 МБ (10% суши)
  → Приэльбрусье, Альпы, Гималаи, Анды…
```

## Формат тайла

```
256×256 int16 → дельта по строкам → gzip (DecompressionStream)
≈ 25–50 КБ на тайл (vs 128 КБ raw)
```

## Предрассчитанные панорамы (альтернатива)

Для точек интереса (вершины, смотровые):
- 720 азимутов × (угол + дистанция) = 3 КБ raw → ~2 КБ сжатых
- Регион 400×400 км, сетка 3 км: ~18 тыс. точек ≈ 35 МБ
- Генерация: минуты на ПК, часы на планету

## Гибрид «ближнее + дальнее»

- **Ближняя зона (0–15 км)**: локальный DEM 30×30 км (~80 КБ), ray-marching на телефоне
- **Дальняя зона (15–200 км)**: предрассчитанные панорамы на сетке 3–5 км
- Слияние: `max(ближний, интерп_дальнего)`

## Источник данных

**Copernicus GLO-90** (AWS Open Data, без регистрации):
- Глобально, 90 м, свежее SRTM
- Скачивание: `aws s3 sync s3://copernicus-dem-90m/...`

## Пайплайн

```
1. Скачать GLO-90 GeoTIFF
2. gdalwarp → EPSG:4326, ресэмплинг под зум
3. dem-to-tiles: int16 → дельта → gzip
4. Манифест index.json с хешами (инкрементальные обновления)
5. GitHub Pages / второй репозиторий для fine
```
