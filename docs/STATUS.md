# Текущее состояние проекта (2026-08-12)

## Что работает

### Ядро
- **Ray-marching горизонта**: 3600 лучей, кривизна Земли + рефракция (k=0.13), Web Worker
- **Terrarium DEM**: глобальный онлайн-слой (AWS), z9–z12 по дальности луча
- **Пики**: 522 780 вершин из planet-260803.osm.pbf, 115 регионов, двуязычные названия
- **Проекция**: азимут/возвышение → экран, подписи с кластеризацией

### UI
- **Canvas 2D**: силуэт горизонта, шкала азимутов, подписи пиков
- **Навигация**: WASD/стрелки, shift+drag, двойной тап, nav pad (8 направлений + GPS)
- **Высота**: кнопки ⬆⬇ ±100м, индикатор текущей высоты
- **Настройки**: список регионов с группировкой, размеры, кнопки скачивания
- **Поиск**: поиск пиков с fallback на другие регионы
- **AR**: getUserMedia + оверлей панорамы
- **Фото**: снимок с подписями → Web Share API
- **PWA**: Service Worker, IndexedDB, офлайн-режим

### i18n
- **12 скриптов**: кириллица, грузинский, армянский, греческий, арабский, тибетский, деванагари, тайский, эфиопский, катакана, хангыль, пиньинь
- **Локали**: ru/en, автоопределение

## Известные проблемы

### 1. Треугольник на своём склоне (отложено)
**Симптом**: стоя на склоне Эльбруса (4127м), гора рендерится как монолитный треугольник до края экрана.

**Причина**: склон выше наблюдателя на 0–15 км → углы 14–23° в слоях 0–2 → заливка от низа экрана.

**Попытки исправления** (откачены):
- Исключить точки выше наблюдателя до 15 км → склон исчез полностью
- Ограничить угол до +10°/+30° → дыры в рендере
- Дистанционные ленты (10 станций 150м–5км) → работало, но сломало far-слой

**Правильное решение** (из мозгового штурма):
- Хранить **профиль углов на фиксированных дистанциях** (не max на корзину)
- Рендерить как **back-to-front ленты** с воздушной перспективой
- Обрезка viewport по возвышению [−25°…+45°]

**Файлы**: `src/core/horizon.ts` (computeLayeredHorizon), `src/ui/panorama.ts` (renderPanorama)

### 2. Подписи пиков висят в воздухе
**Симптом**: маркеры пиков не на силуэте, а выше/ниже.

**Причина**: OSM ele ≠ DEM высота в точке (разные источники).

**Текущий фикс**: `findPeakMarkerPosition` ищет ближайший «горб» на силуэте по азимуту/дистанции.

### 3. Vite SPA-fallback trap
**Симптом**: 404 на JSON возвращает index.html с HTTP 200.

**Фикс**: проверять `Content-Type` перед парсингом.

## Архитектура данных

```
Слой 0 (онлайн): AWS Terrarium z9–z15 (весь мир)
  ↓ fallback
Слой 1 (офлайн): наши int16-патчи /tiles/{region}/{lod}/{x}/{y}.bin
  ↓ fallback
Слой 2 (кеш): IndexedDB (dem-tiles, terrarium, peaks)
```
