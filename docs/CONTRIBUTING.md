# Как участвовать

Проект — MIT/Apache-2.0 (dual). Присылая код, вы соглашаетесь с обеими лицензиями.

## Принципы
- **Без сервера**: всё, что можно прекомпилировать в статику — прекомпилируем
- **Без GPL-зависимостей** в коде приложения (идеи GPL-проектов переписываем с нуля)
- Комментарии и документация — по-русски; идентификаторы и коммиты — по-английски
- Данные вершин правим в **OpenStreetMap**, не в локальных файлах

## С чего начать
1. `good first issue` в Issues
2. Полевые тесты: скриншот «силуэт vs реальность» с координатами — ценнейший вклад
3. Регионы: новый регион = index.json + набор тайлов по инструкции DATA-PIPELINE.md

## Стек
Vanilla TS + Canvas 2D (MVP сознательно без фреймворков и WebGL), Web Workers,
Service Worker, Vite. Инструменты данных — Python (gdal/rasterio).
