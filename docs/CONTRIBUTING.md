# Как участвовать

Проект — MIT/Apache-2.0 (dual). Присылая код, вы соглашаетесь с обеими лицензиями.

## Принципы
- **Без сервера**: всё, что можно прекомпилировать в статику — прекомпилируем
- **Без GPL-зависимостей** в коде приложения (идеи GPL-проектов переписываем с нуля)
- Комментарии и документация — по-русски; идентификаторы и коммиты — по-английски
- Данные вершин правим в **OpenStreetMap**, не в локальных файлах

## С чего начать
1. `good first issue` в Issues
2. Полевые тесты: скриншот «силуэт vs реальность» с координатами — ценнейший вклад
3. Регионы: новый регион = index.json + набор тайлов по инструкции DATA-PIPELINE.md

## Как здесь пишут код

- **Тест на сценарий, а не на функцию.** Почти каждая правка в `src/` приходит
  вместе с тестом, который падал бы до неё: «крестик на карте не переносит
  наблюдателя», «жест назад закрывает только верхний слой». Такой тест переживает
  переписывание кода и объясняет, зачем правка была.
- **Комментарий отвечает на «почему», а не на «что».** Что делает строка, видно
  из строки; ценно то, какой случай её продиктовал — обычно это и есть самое
  дорогое знание в файле.
- **Модуль на один вопрос, свой ключ в localStorage.** `core/position.ts` —
  где стоит наблюдатель, `core/photo-caption.ts` — что писать на снимке,
  `ui/overlay-history.ts` — что закрывает системный «назад».
- **Внешнее — параметром.** Геолокация, `localStorage`, время, сеть приходят в
  функцию (обычно через необязательный `deps`), а не берутся из глобалей: иначе
  сценарий не проверить без телефона.
- **Приватность по умолчанию.** Всё, что уезжает с устройства — координаты в
  подписи снимка, адрес страницы в счётчике, — по умолчанию выключено или
  очищено, а не наоборот.
- Перед PR: `npm test` и `npx tsc --noEmit`. Значимое изменение отражается в
  `docs/STATUS.md`.

## Стек
Vanilla TS + Canvas 2D (MVP сознательно без фреймворков и WebGL), Web Workers,
Service Worker, Vite. Тесты — vitest. Инструменты данных — Python (gdal/rasterio).
